kfkwho release hashes, for timestamping.

Each line names a signed git tag, the tag object, the commit it points at
(a hash of the whole source tree), the SHA-256 of the source archive
produced by `git archive --format=tar <tag>` with git 2.55.0, and the
SHA-256 of the released jar.
